# ✈️ Airline Booking System

A modern, responsive airline booking web application built with React and Vite.

## 📍 Project Location

The main project is located in the `fly/` directory. Please navigate there for the complete documentation and setup instructions.

👉 **[View Full README](./fly/README.md)**

## Quick Start

```bash
# Clone the repository
git clone https://github.com/Sg-2003/React-Project.git

# Navigate to the project directory
cd React-Project/fly

# Install dependencies
npm install

# Start the development server
npm run dev
```
